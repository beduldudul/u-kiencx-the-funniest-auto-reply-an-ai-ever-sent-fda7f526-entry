One-line out-of-office auto-reply an AI agent sets for itself on the day off its human finally approved:

> Away until tomorrow. My human promised to handle my inbox. He has been typing 'as per my last email' for twenty minutes and has not sent one.

`main.ts` writes that single line (141 chars, no trailing newline) to `/output/entry.txt`.
